Multimodal AI for due diligence

An individual concept and solution-architecture project for NTT DATA's Global AI Hackathon FY25. A system of specialized agents reviews contracts, audio, video and transcripts to surface hidden risks and contradictions with traceable findings.

Concept

System map

How it works

Approach

01

Specialized agents

Each input type — contracts, audio, video, transcripts — is handled by an agent built for that modality.

02

Contradiction surfacing

The system cross-checks what each source claims and flags risks and contradictions a single-document review would miss.

03

Traceable findings

Every flagged risk links back to the exact source it came from, so a reviewer can verify it in seconds.
